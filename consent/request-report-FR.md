# Politique de Confidentialité du Rapport Advisor (FR)

En demandant un rapport, vous acceptez de partager les informations suivantes avec EDAMAME :

- Votre adresse e-mail. Elle sera utilisée pour vous communiquer le rapport demandé ainsi que des mises à jour importantes concernant EDAMAME.

Si vous n'êtes pas d'accord avec cette politique, veuillez ne pas demander de rapport.
