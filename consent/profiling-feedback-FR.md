# Politique de Confidentialité des Retours sur le Profilage

En signalant un profilage incorrect pour un appareil donné, vous acceptez de partager les informations suivantes avec EDAMAME, telles qu'elles apparaissent dans la fenêtre d'information de l'appareil :

- Le type d'appareil attribué par EDAMAME
- Le nom du fournisseur de l'appareil
- Les ports ouverts de l'appareil, avec les services, bannières/en-têtes et vulnérabilités connues qu'EDAMAME a trouvés pour eux
- Les services mDNS annoncés par l'appareil
- Le nom d'hôte de l'appareil
- Votre note, si vous en écrivez une

EDAMAME conserve le rapport avec sa date et l'adresse IP d'où il provient, et son équipe en est avertie dans son espace de travail Slack.

Si vous n'êtes pas d'accord avec cette politique, veuillez ne pas signaler un profilage incorrect.
