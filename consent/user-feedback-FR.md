# Politique de Confidentialité des Retours d'Utilisateurs (FR)

En fournissant un retour, vous acceptez de partager les informations suivantes avec EDAMAME :

- La version et la configuration d'EDAMAME Security
- Votre Score de Sécurité numérique
- Votre adresse e-mail si fournie. Celle-ci sera utilisée pour ouvrir un ticket de support si applicable.
- Journaux assainis de l'application (exempts de données personnelles identifiables).

Si vous n'êtes pas d'accord avec cette politique, veuillez ne pas fournir de retour.
